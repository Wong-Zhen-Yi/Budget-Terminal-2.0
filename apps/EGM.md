# Apps

## Overview
`apps/` holds the application workspace. The only workspace package is `budget-terminal-desktop`, located at `apps/desktop` ([CLAUDE.md:Commands]).

## Subdirectories & Boundaries
- `desktop`: [./desktop/EGM.md](./desktop/EGM.md) - The Electron app. It contains the main process, the React renderer, Convex functions, the MCP adapter, and about 177 `probe-*` verification scripts.
