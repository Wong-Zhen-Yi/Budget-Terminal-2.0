# apps/desktop/mcp (MCP adapter source)

## Overview
Source for the standalone MCP adapter, which is bundled to `out/mcp/server.mjs`. It holds the tool catalog, the operations and permissions, the response and output schemas, and the publish step for the plugin bundle. The schemas are generated by `generate-schemas.ts`.

## Interface
- `server.ts` - MCP server entry point.
- `catalog.ts:catalog`, `catalog.ts:connectionTool`, `catalog.ts:toolTitle`.
- `operations.ts:operations`, `operations.ts:newsRefreshOperations`, `operations.ts:optionsRefreshOperations`.
- `features.ts:featureOperations`; request types such as `features.ts:CompanyOverviewRequest` and `features.ts:PortfolioBriefingRequest`.
- `permissions.ts:requiredPermissions`, `permissions.ts:permissionLabels`.
- `prompts.ts:prompts`, `prompts.ts:getPrompt`.
- `response.ts:responseSchema`, `response.ts:responseJsonSchema`, `response.ts:ResponseSelectionError`.
- `output.ts:outputSchema`, `output.ts:envelopeSchema`.
- `toolResult.ts:toolResult`, `toolResult.ts:dynamicToolResult`.
- `errors.ts:McpError`, `errors.ts:errorResult`.
- `runtime.ts:BRIDGE_VERSION`, `runtime.ts:runtimePath`, `runtime.ts:RuntimeDescriptor`.
- `publishBundle.ts:publishBundle`.
- `build.ts` and `generate-schemas.ts` - build and schema-generation scripts. They write `mcp/schemas.json` and `mcp/output-schemas.json`.

## Invariants
- Schemas in `mcp/schemas.json` and `mcp/output-schemas.json` must be current. `npm run probe:mcp` checks this ([CLAUDE.md:Commands]).
- Every MCP-relevant change updates the registry, routes, schemas, plugin bundle, and `docs/local-mcp.md` in the same change ([AGENTS.md:Keep MCP Up to Date]).
- Runtime descriptors and session tokens are never committed ([AGENTS.md:Keep MCP Up to Date]).

## Side Effects
- `generate-schemas.ts` writes the schema JSON files.
- `publishBundle.ts:publishBundle` writes the adapter bundle to the plugin folder. It retries on file locks ([publishBundle.ts:retryFileLock]).
- `runtime.ts:runtimePath` reads and writes the local runtime descriptor ([runtime.ts:RuntimeDescriptor]).

## Verification
- Run: `npm run build:mcp`
- Run: `npm run probe:mcp`
