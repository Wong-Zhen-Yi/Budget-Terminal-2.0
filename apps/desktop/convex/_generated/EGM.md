# convex/_generated

## Overview
Generated Convex runtime bindings and type declarations. Do not edit these files by hand. Regenerate them with the Convex codegen command.

## Interface
- `api.js:api`, `api.js:internal`, `api.js:components` - generated function references.
- `server.js:query`, `server.js:internalQuery`, `server.js:mutation` - generated server builders.
- `api.d.ts`, `dataModel.d.ts`, `server.d.ts` - type declarations for the above.

## Invariants
- Generated files. Regenerate with `npm run convex:codegen`, which is defined at the root `package.json`.

## Side Effects
- None beyond the Convex runtime bindings.

## Verification
- Run: `npm run typecheck`
