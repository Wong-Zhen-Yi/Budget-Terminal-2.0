# docs

## Overview
Human-written guides and design references. Most files are Markdown. Two design folders contain small render scripts. Nothing here is loaded at runtime.

## Subdirectories & Boundaries
- `design-concepts`: [./design-concepts/EGM.md](./design-concepts/EGM.md) - Concept renders for pages and branding.
- `design-prototypes`: [./design-prototypes/EGM.md](./design-prototypes/EGM.md) - Prototype renders for the Settings page and others.
- Other directories (`assets/`, `maintenance/`) hold no code and have no contract.
