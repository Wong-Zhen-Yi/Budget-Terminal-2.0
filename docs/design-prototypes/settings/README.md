# Settings design references

[Back to the design archive](../README.md)

- [Full prototype](settings-prototype.png) and [HTML reference](settings-prototype.html).
- [Compact concept](settings-compact.png).
- [Implementation capture](settings-implemented.png).

The concepts use illustrative settings and provider values. They are standalone
references and do not load application data.

From the repository root, regenerate the full prototype HTML and PNG with:

```bash
npx electron docs/design-prototypes/settings/render.cjs
```

The renderer writes beside these references and uses a temporary Electron profile.
