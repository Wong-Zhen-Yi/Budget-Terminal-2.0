# AVGO UI concepts

Two PNG concepts generated with the built-in image_gen tool, based on the existing AvgoPage content and the PLTR terminal concept as a styling reference. These are design previews; application code has not changed. Financial values, dates, charts, and headlines are illustrative. Generated labels and basis classifications require reconciliation with the existing contracts before implementation.

1. `01-terminal-overview.png`: chart-first workspace with a compact metric strip, market inspector, AI business, revenue mix, and financial trends.
2. `02-business-workbench.png`: business-first workspace with segment composition, AI revenue, cash generation, results and outlook, and a persistent market rail.

## Implementation preview

`03-implemented-preview.png` is an Electron screenshot of the implemented option 1 layout, with the three-series revenue and cash generation chart from option 2. It uses the existing application theme and deterministic AVGO UI test fixtures, not live market data. Detailed AI metrics, financial results, guidance, news, and SEC filings remain available through section tabs. Run `npm run probe:avgo-ui` to verify interactions, startup readiness, error recovery, chart range persistence, and responsive layouts.
