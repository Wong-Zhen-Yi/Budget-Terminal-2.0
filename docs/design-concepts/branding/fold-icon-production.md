Final edit prompt:

```text
Use case: precise-object-edit. Edit target: the supplied selected Budget Terminal Fold logo.
Create the square application-icon version by extracting ONLY the blue folded bird symbol on the left. Preserve its exact silhouette, folds, light-blue and cobalt-blue colors, source-code angle brackets, two horizontal code lines, and three candlesticks. Do not redesign or reinterpret the mark. Remove the entire Budget Terminal wordmark. Center the identical selected symbol on a square uniform midnight navy #080b12 background, with about 12 percent margin left and right and balanced vertical spacing. The symbol should fill about 76 percent of the width, preserving its original proportions. Pristine flat graphic finish. No extra border, no rounded tile, no typography, no watermark, no shadows, no glow, no new elements. Only the selected Fold symbol on navy.
```
